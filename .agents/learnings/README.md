# AI Agent Learnings Knowledge Base

본 디렉터리는 AI 에이전트가 본 프로젝트에서 작업을 진행하면서 얻은 기술적 과제, 해결책, 규약 준수 경험 및 주의사항을 축적하는 영구적인 지식 베이스입니다.
과거의 오류나 실수를 재발시키지 않고, 프로젝트가 진행될수록 코드 품질과 작업 정확도가 지속적으로 향상되도록 운용됩니다.

## 1. 에이전트 행동 규범 (Agent Protocol)

모든 AI 에이전트는 작업 시작 시 및 완료 시 아래 절차를 반드시 준수해야 합니다.

1. **작업 시작 전 (Check Learnings)**:
   - 변경 예정 영역의 `scope`와 관련된 `entries/*.md` 파일을 사전에 확인합니다.
   - 과거에 유사한 작업에서 발생했던 실수나 기술적 제약을 파악한 상태에서 설계를 시작합니다.
2. **작업 완료 후 (Record Learnings)**:
   - 사용자의 피드백을 받거나 컴파일/테스트 실행에서 예기치 않은 오류를 해결한 경우, 반드시 새로운 학습 파일(`entries/<id>.md`)을 작성하거나 기존 지식을 갱신합니다.
   - 일시적인 사소한 실수가 아니라 **재발 가능성이 있는 기술적 제약, 아키텍처 규약, 라이브러리 호환성 문제**를 기록합니다.

## 2. 학습 파일 명세 (`entries/<id>.md`)

각 파일은 아래 YAML 프론트매터와 본문 형식에 따라 작성합니다.

```markdown
---
id: 001-sample-learning-title
title: 간결하고 명확한 제목 작성
date: 2026-10-28
scope: [springboot, java21, mybatis, security, api]
status: active
---

### 배경 및 발생 문제 (Problem / Context)
어떤 작업 중 어떤 문제가 발생했는지를 기술합니다.

### 근본 원인 (Root Cause)
문제의 원인이 무엇이었는지 기술적/구조적 배경을 기술합니다.

### 해결책 및 향후 규칙 (Rule & Solution)
향후 유사한 오류를 방지하기 위해 에이전트가 준수해야 할 규칙을 기술합니다.
```
