# AI Agent Learnings Knowledge Base

本ディレクトリは、AIエージェントが本プロジェクトで作業を進める中で得た技術的課題、解決策、規約違反の経験、および注意事項を蓄積する永続的なナレッジベースです。
過去のエラーや失敗を再発させず、プロジェクトが進むにつれてコード品質と作業精度が持続的に向上するように運用されます。

## 1. エージェントの行動規範（Agent Protocol）

すべてのAIエージェントは、作業の開始時および完了時に以下の手順を必ず遵守しなければなりません。

1. **作業開始前（Check Learnings）**:
   - 変更予定の領域の `scope` に関連する `entries/*.md` ファイルを事前に確認します。
   - 過去に同様のタスクで発生したミスや技術的制約を把握した上で設計を開始します。
2. **作業完了後（Record Learnings）**:
   - ユーザーからのフィードバックを受けたり、コンパイル・テスト実行で予期せぬエラーを解決した場合は、必ず新しいラーニングファイル（`entries/<id>.md`）を作成するか、既存の知見を更新します。
   - 一時的なケアレスミスではなく、**再発の可能性がある技術的制約、アーキテクチャ規約、ライブラリの互換性問題**を記録します。

## 2. ラーニングファイルの仕様（`entries/<id>.md`）

各ファイルは以下のYAMLフロントマターと本文形式に従って記述します。

```markdown
---
id: 001-sample-learning-title
title: 簡潔かつ明確なタイトルの記述
date: 2026-10-19
scope: [springboot, java21, mybatis, security, api]
status: active
---

### 背景・発生した問題（Problem / Context）
どのような作業中に、どのような問題が発生したかを記述します。

### 根本原因（Root Cause）
問題の原因が何であったのか、技術的・構造的な背景を記述します。

### 解決策および今後のルール（Rule & Solution）
今後同様のエラーを防ぐためにエージェントが遵守すべきルールを記述します。
```
